# PBMC 5k scATAC tutorial

`pbmc_tutorial.ipynb` demonstrates scCHART using the public 10x Genomics PBMC 5k scATAC dataset. The analysis contains 3,921 cells across nine annotated cell types and 250,000 genome tiles.

The notebook uses `scchart.Heterogeneity` to calculate structural and regulatory programme heterogeneity, including sampling-based null calibration. It visualizes results using `scchart.pl`, compares populations at matched sequencing depth on the programme axis, and saves the fitted results.

The notebook includes the outputs from a completed run.

## Run the tutorial

From the repository root:

```bash
uv sync --group tutorial
uv run python examples/pbmc_tutorial/prepare_data.py
cd examples/pbmc_tutorial
uv run jupyter lab pbmc_tutorial.ipynb
```

The data preparation step downloads approximately 840 MB and writes the prepared dataset to `data/`.

Structural null calibration within `model.fit()` is the most computationally expensive step. The notebook reports measured execution times for its computationally intensive steps.

Optional environment variables:

- `SCCHART_N_JOBS`: Number of parallel null chains (structural and programme; default: `min(8, CPU count)`). Does not change the calculated results.
- `SCCHART_TUTORIAL_MATCHED_DEPTH=1`: Also runs structural matched-depth comparison, which is substantially more computationally expensive.
- `SCCHART_PBMC_DATA`: Path to an existing prepared input dataset.

The notebook writes results to `data/pbmc5k_scchart_results.h5ad`. Figures are displayed in the notebook and are not saved separately.

## Data source and preparation

`prepare_data.py` obtains the annotated PBMC 5k dataset distributed with the SnapATAC2 tutorials:

```python
snapatac2.datasets.pbmc5k(type="annotated_h5ad")
```

The source includes 500-bp genome tiles, cell-type annotations, and a UMAP embedding.

The preparation script verifies the downloaded file's SHA-256 checksum against the SnapATAC2 dataset registry, excludes MAIT, NK, and pDC cells, and retains 250,000 selected tiles.

To use an existing copy of `atac_pbmc_5k_annotated.h5ad`, provide the `--source` option to `prepare_data.py`.

The dataset is not included in the scCHART repository. The original sequencing data were generated by 10x Genomics.
